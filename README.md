Git Version Control & Repository Management Project
Project Overview

This project demonstrates practical implementation of Git Version Control and Repository Management concepts using Git CLI commands. It covers repository initialization, file tracking, commit history management, version recovery, and repository maintenance operations.

Objectives
Understand Git workflow
Learn repository management
Practice version control operations
Track and manage source code changes
Explore commit history and recovery techniques
Git Commands Practiced
Repository Management
git init
git status
git status -s
Staging Operations
git add .
git add filename
Commit Management
git commit -m "message"
git commit -am "message"
Configuration
git config --global user.name
git config --global user.email
History & Inspection
git log
git log --oneline
git show
File Management
git mv
git rm
git restore
git ls-files
git ls-tree
Recovery & Reset
git reset --soft HEAD~1
